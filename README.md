🛡 LogGuard SOC AI

LogGuard SOC AI — учебный проект в области кибербезопасности, представляющий собой упрощённую SOC / SIEM-платформу с графическим интерфейсом, AI-оценкой риска и поведенческим анализом (UEBA).

Проект предназначен для демонстрации принципов:

анализа журналов событий (логов)

выявления кибератак

корреляции событий

применения AI в информационной безопасности



---

🚀 Основные возможности

📂 Загрузка логов произвольного формата (CSV)

🔄 Нормализация логов к единой структуре

🎯 Симулятор кибератак (каждый запуск — разные атаки)

🤖 AI Risk Score (оценка уровня угрозы)

👤 UEBA (User & Entity Behavior Analytics)

🧠 AI-классификация типа атаки

🔗 Корреляция событий

🧬 Сопоставление с MITRE ATT&CK

📈 Таймлайн атак

🖥 Современный GUI

📦 Сборка в .exe под Windows



---

🧠 Используемые технологии

Python 3.10

customtkinter — современный GUI

pandas — обработка логов

scikit-learn — AI-модели

matplotlib — визуализация

PyInstaller — сборка .exe

GitHub Actions — автоматическая сборка

▶️ Как запустить проект локально

1️⃣ Клонировать репозиторий

`git clone https://github.com/Emil7652/LogGuard_SOC`

`cd LogGuard`

2️⃣ Установить зависимости

`pip install -r requirements.txt`

3️⃣ Запустить приложение

`python source/main.py`

📦 Сборка EXE (Windows)

Локально

`pyinstaller --windowed --icon=assets/logguard_icon.ico source/main.py`

Готовый файл появится в папке:

`dist/main/main.exe`

Через GitHub Actions

Проект автоматически собирается в .exe

Файл доступен во вкладке Releases



---

⚙️ GitHub Actions

Проект использует GitHub Actions для автоматической сборки .exe при каждом push в ветку main.

Workflow находится в:

.github/workflows/build_exe.yml
